# LUMEN — front end

Reprodução navegável do protótipo Figma Make fornecido. O projeto usa HTML, CSS e JavaScript puros, sem dependências de instalação.

## Executar

Abra `index.html` em um navegador, ou sirva esta pasta localmente com um servidor estático. A navegação usa rotas com `#` para funcionar também ao abrir o arquivo diretamente.

## Escopo

Inclui página inicial, login, cadastro, denúncia anônima, fluxo de nova denúncia, dashboard, listagem, estatísticas, notificações, página sobre, configurações e páginas legais. Os dados criados nos formulários ficam somente no `localStorage` do navegador. Login com Google, envio de e-mail e integração com prefeitura exigem serviços externos e são apresentados como indisponíveis nesta demonstração de front end. As páginas legais contêm texto demonstrativo e precisam ser substituídas antes de uso real.
